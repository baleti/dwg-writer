# DWG project scope (user, 2026-10-17): same goal as the rvt project
Own tooling, no AutoCAD needed at runtime, to READ, WRITE, EDIT and VIEW .dwg files with CORRECT GRAPHICS on model space AND layouts (sheets), viewports and views.
1. READ (parser, c1-dwg, ~/dwg-research): all versions R12-R2018+ (AC1009..AC1032), every entity class with true geometry, layers, linetypes, text/dim/mtext/leader styles, blocks and attributes, xrefs, hatches and patterns, images, OLE, proxy objects, layouts, viewports, plot settings, named views, UCS, object properties and extended data; accuracy tables per class and per version against oracle exports (DXF, JSON dump, plots).
2. WRITE and EDIT: generate and modify valid .dwg files that AutoCAD opens without audit errors (R2000 or R2018 first), covering all common entity types, blocks and inserts, layers, linetypes, styles, hatches, dimensions, layouts and viewports, xdata; round-trip editing of existing files without losing unknown objects (preserve what we do not understand byte-exact). Test in the offline AutoCAD VM (open, AUDIT, plot).
3. VIEW: a viewer (like rvt-viewer / rvt-sheets) with correct graphics: model space plan view, paper space layouts as sheets with viewports (scale, clipping, frozen layers per viewport, layer overrides), plot styles (CTB/STB colours, lineweights, screening, fill), linetype patterns with scale (LTSCALE/CELTSCALE/PSLTSCALE), hatch patterns, text/mtext with fonts (SHX, TTF) and positioning, dimension rendering from dimstyles, leaders, blocks with attributes, annotative scales, xref display, images, 3D solids/surfaces shaded; measured against AutoCAD's own plots from the offline VM (numeric checks first, image diffs second, review folder for the user to compare, like ~/review-compare).
4. ORACLE: offline AutoCAD VM (host2) and ODA File Converter as EXTERNAL checks only (no code/constants from them). Demo must stay stable; nothing proprietary leaves the user's machines; no pushes without asking.
Agents: c1-dwg (parser/reader), c3-dwgvm (VM + oracle tools), later dwg-writer and dwg-viewer when the parser yields geometry.
